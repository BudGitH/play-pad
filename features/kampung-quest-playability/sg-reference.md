# Singapore estate reference sheet (HDB blocks, void decks, hawker centre)

Owner ask: the HDB blocks, void decks and the food court should look like the real thing in Singapore. This sheet lists the sources looked at and the visual traits the game reproduces. **Stated** = what a source says or a reference photo plainly shows; **Inferred** = our reading or common knowledge not backed by a cited source here. Photos were viewed for reference only (saved outside the repo); no third-party image is committed or shipped.
