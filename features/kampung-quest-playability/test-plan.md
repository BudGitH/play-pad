## Test cases

### Happy path

- [x] Open the full map, pick the tailor, Go here, arrive: the target clears; a child finds the camel yard from the map.
- [x] Ride a camel, a horse and a pony faster than running, and get down on free ground.
- [x] Pick Girl on a first run, dress her at the tailor, wear the ihram and put the look back.
- [x] Drive a car at 2.5x run speed; it sits on the ground and cannot be walked through.
- [x] Hide the tawaf card, walk the round by hand, restore the card; Walk for me tucks it away and brings it back.
- [x] Say hi to a kid, get a reply and a wave; a football event starts, runs and cleans up.
- [x] Rest in one tap; Pray from the status card goes wudu then prayer in one flow.

### Edge cases (boundaries)

- [x] Zoom limits and the pan clamp on the full map; a place in the other holy city has no Go here.
- [x] A camel at the Haram edge stops with a friendly line; no ride into a no-drive zone.
- [x] A hostile or damaged `hero` in the save is sanitised (junk, inherited keys).
- [x] A vehicle bumping head-on into a parked one stops; a glancing scrape only slows.
- [x] An event never starts during a prayer, a rite, a menu or while riding.
- [x] A keyboard iPad (`pointer: fine`) still gets touch controls; a Mac without touch points does not.
- [x] `speechSynthesis` missing or muted: no hint is spoken, none counts as heard.

### Error paths

- [x] A lost WebGL context shows the friendly card and a restored one hides it.
- [x] Blocked `file://` textures: the procedural stand-ins keep the world running with no console errors.
- [x] Rest refused while a fard prayer is due (a kind toast), never offered at full energy.

### Non-functional checks

- [x] **Accuracy:** religious logic untouched (`KQ.Sim.Prayer`, `KQ.Sim.Umrah`; the girl's tahallul uses the sim's existing `lock`); every girl outfit modest (unit); men in ihram bare-headed (`crowd-pilgrim.test.mjs`).
- [x] **Risk:** the new save fields (`hero`, `prefs.seen`) are clamped and whitelisted; every label enters the DOM through `textContent`.
- [x] **Compliance:** new CC0 photos (half-size copies) credited in `assets/CREDITS.md`; no brand names in the Singapore signage.
- [ ] **Performance:** the draw-call sweep at the busy views (bus stop, hawker, void deck, rides lot) and a real-GPU / real-iPad run (ledger `draw-call-budget-pressure`, AC-P22 / P23).

## How to run

```
npm run check && npm run secrets && npm run test:kq
npm run smoke:kq:playability          # the playability specs (use PW_PORT=<port> when another checkout is running)
npm run smoke:kq                      # every Kampung Quest browser spec, minus @slow
PW_PORT=5606 PW_CHROMIUM_PATH=/opt/pw-browsers/chromium npx playwright test tests/kampung-quest-map.spec.mjs --project=kampung-quest --workers=1
npm run perf:kq                       # the @slow throttled-frame probe
```
