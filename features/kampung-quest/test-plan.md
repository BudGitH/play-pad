## Test cases

### Happy path

- [x] A new game starts at 07:00 day 1 with nothing due. _(save, prayer)_
- [x] Prata mission: buy → deliver → +5 coins + sticker. _(missions)_
- [x] Zohor due → wudu in order → 4 raka'at → done, praised, missions resume. _(prayer)_
- [x] Eat a dish: coins down, hunger up. _(needs-economy)_
- [x] Save → reload → same clock, coins, needs, mission step, prayer step. _(save)_

### Edge cases (boundaries)

- [x] Clock rollover at midnight, several days in one tick, NaN/negative dt. _(clock)_
- [x] Coins exactly 0 and 1 short: singular/plural copy. _(needs-economy)_
- [x] Idle through two prayers (Zohor → Asar, Maghrib → Isyak), a time jump across the whole day, Isyak across midnight. _(prayer)_
- [x] Prayer due while a mission is active: mission kept, resumes. _(missions)_
- [x] Reload mid-prayer: resumes at the start of the step; wudu kept if complete. _(prayer, save)_
- [x] Subuh qunut skipped / performed. _(prayer)_
- [x] Hawkers: one always at a stall during opening hours. _(schedule)_

### Error paths

- [x] Wrong wudu or prayer step: `ok:false` + gentle hint; nothing lost. _(prayer)_
- [x] Corrupt / wrong-type / hostile save, throwing or missing storage → new game, no throw. _(save)_
- [x] Unknown NPC id, NaN minute → valid fallback routine. _(schedule)_
- [x] Unknown mission id, second mission while one is active, re-accepting a finished one. _(missions)_

### Non-functional checks

- [x] **Accuracy:** raka'at counts, step plan structure, wudu order/fard flags and Subuh-ends-at-Syuruk asserted against the sources cited in the header of `js/sim/prayer.js`. A religious-accuracy read-through by the owner is still recommended before release.
- [x] **Risk:** the save is parsed defensively (schema, clamps, unknown ids dropped, `__proto__` safe, size cap); no network, DOM or `Date.now` in `js/sim`.
- [x] **Compliance / child safety:** menu is halal (flag + forbidden-word scan); mission, chat and sticker text scanned for violence, crime, gambling, alcohol and pork.

```
npx eslint games/kampung-quest/js/sim tests/kampung-quest
```
