# Neon Rush — game-local contract

> Constraints for anyone (human or Claude) touching this game. The project-wide rules in the root `CLAUDE.md` / `docs/` still apply; this file adds the game-specific ones.

## Hard constraints

- **Single game file + vendored deps:** all game code is in `index.html`. Its siblings: `three.min.js`, `GLTFLoader.js`, this doc, and `assets/`.
- **Three.js is vendored at r0.147.0 (UMD), not CDN.** r147 is the **last release with classic-script (`examples/js`) loaders** — needed because `GLTFLoader.js` must attach `THREE.GLTFLoader` to the global (ES-module builds break under `file://`; a CDN tag breaks the deployed CSP `script-src 'self'`). **Do not upgrade past r147** without solving the module/file:// problem, and keep `three.min.js` + `GLTFLoader.js` version-matched.
- **CSP note (deploy):** GLTFLoader loads GLB-embedded textures as `blob:` object-URLs (on Chrome via `ImageBitmapLoader.fetch`), so the site CSP **must** keep `blob:` in **both `img-src` and `connect-src`** (`_headers`). Miss either and models render grey on the deployed origin while localhost (no CSP) looks fine — see LEARNINGS PLAY-005 v4.
- **Vendored assets (`assets/`), all CC0/free — see `assets/CREDITS.md`:**
  - `models/` — 3 animated GLB characters (KayKit Rogue_Hooded → Urban Runner, Quaternius Astronaut → Star Rider, three.js RobotExpressive → Neon Bot). CC0.
  - `models/city/` — KayKit City Builder Bits (CC0): `building_A..H.glb` (textured roadside city; the neon boxes retreat to skyline duty when these load) + `car_police.glb` (the hover-patrol chaser; primitive drone is its fallback). Converted from the pack's gltf+bin to single-file GLBs with the texture embedded.
  - `audio/` — `music.ogg` (ansimuz "Cyber Runner", CC0) + 6 Kenney sci-fi SFX (CC0).
  - `CREDITS.md` **must ship** with the game (shown in small print on the setup screen too). Keep it current when assets change.
- **Graceful degradation is mandatory — the game must never DEPEND on an asset loading:**
  - GLB models + Web-Audio SFX load via `fetch`/GLTFLoader. On any failure the **primitive-built skins** (still in `SKIN_BUILDERS`) and the **synth voices** (still in `AudioManager`) take over automatically. Never delete those fallbacks.
  - **`file://` caveat:** Chrome blocks `fetch`/XHR to `file://`, so a _double-clicked_ `index.html` runs the FALLBACKS (primitive models + synth SFX) — still fully playable. Real models + SFX need an http(s) origin: the deployed Cloudflare site, any static server, or `python -m http.server`. Music (`<audio>` element) works from `file://` too. The deployed site (what players actually use) is always full-featured.
- **Audio-files are now allowed** (this supersedes the original "synth only" rule). The drone siren stays synth (it's a live proximity layer). Every file voice keeps a synth fallback.
- **Performance:** target 60fps. Pools for obstacles/coins/particles; one `AnimationMixer` per active skin updated in the fixed-step tick; fixed-timestep sim; pause on `visibilitychange`. **Quality tiers** (`TIERS`, session-scoped): high (dpr ≤2, PCFSoft 1024) / medium (default on coarse pointers or ≤4 cores: dpr ≤1.5, PCF 512) / low (auto-downgrade only: dpr 1, shadows off, no streak decals/sign flicker/PMREM). An EMA of real frame time drops one tier after >22 ms for 2.5 s (never upgrades mid-run). **Draw-call budget:** high ≤170, low ≤110 (measured ≈75-90 main pass; `renderer.info` is reset _after_ three's shadow pass, so add `__neon.render.shadowCasters`). Many-of-a-kind scenery is `InstancedMesh` (lamps, towers, signs, halos, coins); obstacles are 3-4 merged meshes each. No per-frame allocation in hot paths; no PointLights.
- **Colour pipeline:** `THREE.ColorManagement.legacyMode = false` (set at the top of the script) so hex colours are sRGB-authored; every colour `CanvasTexture` is tagged `sRGBEncoding`. Fog is mixed _after_ output encoding in r147, so `scene.fog.color` holds display values (set via `setRGB`/`setHSL`, never `set(hex)`). Additive things (`patchAdditiveFog`) fade to black in fog.

## Module structure (inside index.html, section-bannered)

| Module             | Owns                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| ------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `PlayerController` | lane state + lerp, jump/slide physics, input (arrows + swipes), drives the GLTF state machine or the primitive `animateSkin`; lean (roll + yaw), landing event + camera dip, blob shadow, `crashTick` (death clip + knock-back, no pinwheel)                                                                                                                                                                                                                                                                                                                                            |
| GLTF skins         | `MODEL_CFG` = per-skin **animation table** (state → `{n clip, ts, once, fit, tie}` or `{as: state}` alias; states idle/run/jumpStart/air/land/slide/crash) + per-skin `fx` material tweaks, fresnel `rim`, `crouch` pose. `buildGltfSkin` builds `wrap → pose (feet pivot: crouch / landing squash / board lift) → rig` and the `ctrl` state machine (re-arms faded-out actions, LoopOnce clamp, Bot jump fitted to airtime, board 360, ride bob). `preloadModels` async-loads; `applySkin` hot-swaps GLB↔primitive and `ctrl.reset()` clears mixer + pose (T-pose / death-pose guard) |
| World / scene      | `THREE scene` block: lighting rig (hemi + moon key + magenta/cyan rims), skydome (equator = horizon, sun on it) + PMREM, road / curb / sidewalk / outer ground, roadside row (`roadside`: neon boxes until the KayKit GLBs load, then GLB clones on the facade line; night grade + lit-window emissive mask + roofline trims + instanced neon signs), instanced lamps / towers / antennas, skyline ring, speed lines. `worldTick(move)` advances every scrolling layer, `worldAnim` runs flicker/antennas, `applyQuality` switches tiers                                                |
| `ObstacleSpawner`  | pooled barriers/trains (shared atlas materials, ≤4 merged meshes each), instanced coins + halo + collect burst, pickups (crystal + cage + halo + ground ring), fairness pattern table; calls `worldTick`                                                                                                                                                                                                                                                                                                                                                                                |
| `CollisionEngine`  | AABB tests, hoverboard i-frames, near-miss → drone                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `UIManager`        | screen router (`show()` teardown chokepoint), HUD, shop, live region, instant-start countdown skip                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| Particle FX + sky  | `makeSpriteTexture`/`makeParticles` (pooled `THREE.Points`, additive-blend, colour→black fade); `shieldAura` (gold orbiting swirl, replaces the old shield sphere) via `updateShieldAura`; `patrolFX` hover-jet exhaust (world-space pool, replaces the police-car underglow plane) via `updatePatrolFX`; skydome (`makeSkyTexture`: equator = horizon, banded sun on it) + starfield; `updateSky` sways the dome ±0.06 rad and drifts the fog hue around violet only (clamped, never red)                                                                                              |
| `AudioManager`     | file music (`<audio>`) + decoded SFX buffers, each with a synth fallback; drone synth; mute persistence                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `SaveManager`      | the single localStorage gateway (`playpad.neonRush.v1`, versioned, sanitized, fail-soft)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |

## Instant start

First run is a snappy 3-2-1-GO at 300ms/step (~1.2s); **retries skip to a "GO!" flash** (~0.2s); **any tap/key during the countdown skips it**. Tune in `startRun`.

## Testing

`window.__neon` exposes state + deterministic drivers (`forceSpawn`/`setSpeed`/`setDistance`/`setTension`/`step(ms)`/`crash`/`givePowerup`/`setQuality(tier)`) plus `.skin` (GLB vs primitive, state name, **per-action `weights` + `__sum`**, `clips`, `headY`/`topY`, bone `spread`, `pose`) — never verify animation from the state name, read `weights`/`spread` — and `.audio`, `.render` (`drawCalls`, `triangles`, `shadowCasters`), `.quality`, `.camera` (`fov`, `laneVisible`), `.scene.groundGap()`, `.three` (raw scene/camera/renderer for QA). Headless preview throttles rAF and often can't screenshot the WebGL canvas — verify logic through `step()` and the probes; verify visuals with occasional screenshots.
