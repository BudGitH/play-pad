# Sunset Stride — game-local contract

> Constraints for anyone (human or Claude) touching this game. The project-wide rules in the root `CLAUDE.md` / `docs/` still apply; this file adds the game-specific ones. (Formerly Neon Rush — renamed and reworked in PLAY-007; the old URL redirects via `_redirects`.)

## Hard constraints

- **Single game file + vendored deps:** all game code is in `index.html`. Siblings: `three.min.js`, `GLTFLoader.js`, this doc, and `assets/`.
- **Three.js is vendored at r0.147.0 (UMD), not CDN.** r147 is the **last release with classic-script (`examples/js`) loaders** — needed because `GLTFLoader.js` must attach `THREE.GLTFLoader` to the global (ES-module builds break under `file://`; a CDN tag breaks the deployed CSP `script-src 'self'`). **Do not upgrade past r147** without solving the module/file:// problem, and keep `three.min.js` + `GLTFLoader.js` version-matched.
- **CSP note (deploy):** GLTFLoader loads GLB-embedded textures as `blob:` object-URLs, so the site CSP **must** keep `blob:` in **both `img-src` and `connect-src`** (`_headers`). (The current GLBs carry no embedded textures — skins are separate PNGs — but keep the rule: a future model with an embedded texture renders grey without it on the deployed origin while localhost looks fine.)
- **Vendored assets (`assets/`), all CC0 — see `assets/CREDITS.md`:**
  - `models/runner.glb` (Quaternius human; clips `Run Jump Death Walk`) + `models/skins/*.png` (six 32×32 palettes = the shop outfits) + `models/dog.glb` (Quaternius dog; clip `Walking`). Converted from FBX once (recipe in CREDITS).
  - `textures/*.jpg` — ambientCG photo materials at 512 px (+ two normal maps).
  - `audio/` — `music.ogg` (chill lo-fi loop) + 6 Kenney SFX.
  - `CREDITS.md` **must ship** with the game (shown in small print on the setup screen too). Keep it current when assets change.
- **Changed asset = new filename (or a `?v=` on its URL).** `assets/*` are un-hashed and cached for 7 days (`_headers`) while `index.html` revalidates, and `runner.glb`, `skins/*.png` and the code are coupled (clip names, the `POSES` bone table, palette rows) — a stale cached asset against new code could misbehave for up to a week.
- **Graceful degradation is mandatory — the game must never DEPEND on an asset loading.** Textures → procedural stand-ins (`TexLib`), models → primitive runner/dogs (`makePrimRunner` / `makePrimDog`), audio → synth voices (`AudioManager`). Never delete those fallbacks. **`file://` caveat:** Chrome blocks `fetch` and WebGL uploads of `file://` images, so `CAN_FETCH` is false there and the game runs entirely on the fallbacks (still fully playable, no console errors). Music (`<audio>`) works from `file://` too. The deployed site (what players use) is always full-featured.
- **No T-pose, ever (owner complaint, PLAY-007):** three blends `(1 − Σweights)` of the **bind pose** (a T-pose) into the result, so the runner's clip weights are re-normalised to sum to exactly 1 every frame (`view.update`), a GLB runner stays hidden until its first real pose (`view.ready`), and the primitive fallback never has arms out. `__stride.skin.weights.__sum` must read 1 in every state — the probe checks it.
- **Slide / stumble are authored, not squashed:** the pack has no slide clip, so `POSES` (model-space limb directions) is blended over the mixer by `applyPose`. **Never scale the model non-uniformly** (the old crouch squashed the model; the probe checks `scaleUniform`). A slide also lowers the body so the lowest bone rests ≈ 9 cm above the pavement.
- **Performance:** 60 fps target. Pools for obstacles / coins; one `AnimationMixer` per skinned model; fixed-timestep sim; real pause on `visibilitychange` hidden / window `blur` mid-run. **Quality tiers** (`TIERS`, session-scoped): high (dpr ≤ 2, shadow 1024) / medium (default on coarse pointers or ≤ 4 cores) / low (auto-downgrade only: dpr 1, no shadows, no normal maps, no IBL). An EMA of real frame time drops one tier after > 22 ms for 2.5 s (never upgrades mid-run). **Draw-call budget:** high ≤ 170, low ≤ 110 (measured ≈ 75 main pass; add `__stride.render.shadowCasters`). Many-of-a-kind scenery is `InstancedMesh` (trees, lamps, coins); obstacles are 2–3 merged meshes each. No per-frame allocation in hot paths; no PointLights.
- **Colour pipeline:** `THREE.ColorManagement.legacyMode = false`, ACES tone mapping; every colour `CanvasTexture` is tagged `sRGBEncoding`. Fog is mixed _after_ output encoding in r147, so `scene.fog.color` holds **display** values (`setRGB`, never `set(hex)`), equal to the sky's horizon colour (`HAZE`). Sky / skyline / pickup faces are `toneMapped: false`.

## The chase rules (what the player is told on the setup screen)

`gap` = metres between the runner and the nearest dog, measured behind (+z). A **frontal** hit while `gap ≥ GAP_DANGER (2.7)` is a **stumble**: speed × 0.55 (recovers linearly over 2.2 s), `gap = GAP_HIT (1.7)`, 1.4 s of i-frames (2.2 s when it was a van / truck / bus, which also bounces you to a free lane). A frontal hit while `gap < GAP_DANGER` is **caught** (run over). The pack falls back at 0.35 m/s toward `GAP_CALM (3.8)`. A hit while changing lane into a van/truck is a **side-scrape**: bounce back, small gap penalty, never fatal. A **close call** (late dodge past an approaching obstacle) is +10 and pushes the dogs back 0.8 m. The camera sits back / high so the pack is on screen at the bottom whenever `gap` is small (phones see them more).

## Instant start, pause

First run is a snappy 3-2-1-GO at 300 ms/step; **retries skip to a "GO!" flash**; **any tap/key during the countdown skips it**. Hidden tab or window blur during `running`/`countdown` sets `paused`: `tick()` and the rAF loop freeze, audio suspends, a **"Paused" overlay** (`#pause`) comes up; Space / Enter / P resume, Esc quits, resuming replays a 3-2-1. A crashed (caught) run is never paused; `onCaught` banks synchronously.

## Testing

`window.__stride` exposes state + deterministic drivers (`forceRun` `forceSpawn(type, lane, z, variant)` `clearObstacles` `setSpeed` `setDistance` `setGap` `step(ms)` `input(action)` `hit` `crash` `givePowerup` `grantCoins` `pause` / `resume` `show` `setQuality(tier)` `seed(n)` and `freeze(true)` / `freeze(2)` — keep rendering vs stop everything — for screenshots) plus probes: `.skin` (kind, state, **per-action `weights` + `__sum`**, `spread`, `handSpan`, `legGap`, `lowestBoneY`, `scaleUniform`), `.dogs` (gap + per-dog z / onScreen), `.world` (texture status, model readiness), `.render`, `.quality`, `.camera` (`laneVisible`), `.thumbs()`, `.three`. **Never verify animation from the state name — read `weights` / `spread`.** `node tests/probes/stride-probe.mjs` runs the full AC probe suite (needs the static server and a Chromium; ≈ 2 min). Headless preview throttles rAF, so use `step()` / `freeze(true)` for screenshots.
